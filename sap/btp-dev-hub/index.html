两分钟上手

验证通过 · 本机预览（无需任何安装）

站内所有页面、代码、数据都是静态文件，三种打开方式任选：

Shell
# 方式 A: Python 自带 HTTP 服务(推荐, 功能最全)
cd btp-dev-hub
python3 -m http.server 8000
# 浏览器打开 http://localhost:8000/

# 方式 B: 直接双击 index.html (file:// 打开也可浏览大部分内容,
#          但浏览器同源策略会限制部分 JS 交互, 代码复制不受影响)

# 方式 C: 已有 VS Code / 任意静态服务器, 指向 btp-dev-hub 目录即可

在“示例工程”页可拿到两个 CAP 工程（Node.js 版已在本机实测运行）、Fiori 应用、iFlow 建模手册与全套测试数据。

Text
btp-dev-hub/
├── index.html                  ← 你现在在这里

提示 · 怎么改这个站

页面由 tools/sitegen/ 下的 Python 模板生成，改完重跑 python3 tools/sitegen/generate.py 即可；测试数据统一维护在 tools/make_data.py，重跑会同时刷新 CSV 与 JSON。
