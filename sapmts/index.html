見込生産（MTS / Make-to-Stock）实战训练站

一条完整可跑的 見込生産（見込生産 = 予測で作り、在庫から納める） 场景：需要予測と PIR → MRP → 計画手配 → 製造指図 → 部品出庫 261 → 実績 → 完成品入庫 101（自由在庫）→ 受注が在庫から引当てる（ATP）→ 出荷 PGI 601 → 請求 → 差異計算と決済。 主口径是 S/4HANA On-Premise，同时给出 Public Cloud（SSCUI / スコープアイテム） 的差异对照。

本站与姊妹站 sapmto（受注生産 / MTO）、sapeto（受注設計生産 / ETO） 成一套： 同一个「受注 → 出荷 → 請求」外壳，唯一不同的是「计划起点」和「库存归谁」——MTS 是 PIR 起点 + 自由在庫，MTO 是 受注起点 + 受注在庫（特在 E）。做完本题，你应该能只用一句话说清这两者的分水岭。

1. 这个场景教什么

SAP 的「見込生産（MTS）」不是「不做计划的生产」，恰恰相反：它是先做需求预测、把预测登进系统（計画独立所要量 / PIR）、再让 MRP 把预测变成补货。 它和 MTO 的差别只在两个问题：① 生产是谁引起的？（预测 还是 受注）② 造出来的库存归谁？（全公司可用的自由在庫 还是 只能给某一张受注的個別在庫 E）。 答对这两个问题，见下面对照表——本站所有配置和练习都是围绕这两个问题展开的。

① 练习配置手顺（详细 SPRO）

C0〜C15 の配置 STEP ＋ C16 Public Cloud 差异对照：从品目主数据（販売組織2 / MRP2 安全在庫 / MRP3 戦略グループと消費モード / MRP4）、標準原価計算（CK11N・CK40N・CK24）、計画方針グループ（10/11/30/40/70）、所要量タイプ／クラス、明細カテゴリ・納入日程行カテゴリ（在庫確認 ON）、ATP 控制、MRP 侧设置 到 出荷・請求・転記。每步给出 IMG 路径、事务码、输入值、在自系统中的确认方法。

配置约 150 分

② 练习流程（5 个实操）

练习① 需要予測と PIR（MD61 → MD62 → MD04）→ 练习② MRP 実行と調達提案（MD01N → MD04 → 計画手配 → 指図）→ 练习③ 製造と入庫（261 / CO11N / 101 → 自由在庫）→ 练习④ 受注・引当・出荷・請求（VA01 / ATP / VL01N / PGI / VF01）→ 练习⑤ 月末処理と発展（差異計算 KKS1/KKS2 → 決済 KO88/CO88、棚卸、欠品・安全在庫切れ、故障対照表 12 項）。

实操约 240 分

③ 术语与设计（为什么会这样）

見込生産 3 方式的对照（品目レベル / 最終組立レベル / 組立レベル＝戦略 10・40・70 系）、PIR 与消費モード、自由在庫（MARD/MCHB）与 ATP 引当、MRP 的网络变更与净需求算、標準原価与差異、受注在庫との違い、関連テーブル、S/4HANA 变更点、10 个常见误解。

概念约 60 分

④ 能力测试 + 验收清单

28 题（概念 10 / 配置 9 / 流程 6 / 故障 3）× 点击判分 + 解说，外加一份实机验收清单：把系统里的证据（PIR 的 PBED、MD04 的预计行、自由在庫、差異の決済ログ）逐条核对，才算「这个场景跑通了」。

测试约 30 分

2. 训练场景设定

场景取自典型「量产型见込品」：客户按库存订货，工厂按月度预测先造、放在自由在庫，客户下单后直接从库存引当、出荷。受注不产生新的生产需求（而是消费（消費）已有的 PIR）——这就是戦略グループ 40 的舞台。

7. 关于标准值的立场（请务必读）

本教程的做法 SAP 的标准设定会随版本、行业解决方案、激活的业务功能、以及既有项目改造而不同。本场景里差异最大的三处： ① 戦略グループ（10/11/30/40/70 的哪一个、以及它指向的所要量タイプ／クラス）； ② PIR 的消费行为（消费モード・逆/順消費期間，甚至「是消费还是消减」）； ③ 受注在庫的评价（MTS 用的是自由在庫，但自由在庫的金额来自 Material Ledger／標準価格，设置差体现在金额而不是有无）。
因此本站的原则是：把「标准值的通常情况」写清楚，但每一个值都配一条「在你自己的系统里怎么确认」的手顺， 并给出配置练习（自己建 Z001 / ZTAN / ZCP）确保即使标准值与本站不同，练习依然成立。教学以「机制正确」为优先，不以背标准值为目标。
另外提醒：网上常把「組立レベルでの計画」写成戦略 40、把「最終組立ありの計画」写成 30。本站依据 SAP Help / SAP 支持资料核对后采用：40 = 最終組立ありの計画，70 = 組立品目（組立）レベルでの計画。请用 OPPS/OPPT 在自己系统里核对描述文字。
