一、概念（1〜10）

概念 見込生産の起点

1. 見込生産（MTS）において、生産・調達のきっかけ（計画の起点）はどれか。

受注（受注明細）
需要予測（計画独立所要量 PIR）
在庫の棚卸差異
購買依頼
MTS は「予測で作り、在庫から納める」。受注は需要を创造せず、PIR を消費して在庫を掴みます（概念 1）。
概念 在庫区分

2. 見込生産の完成品が入る在庫はどれか。

受注在庫（特別在庫区分 E・MSKA）
プロジェクト在庫（特別在庫区分 Q・MSPR）
自由在庫（非制限利用在庫・MARD/MCHB）
預託在庫（MSKU）
MTS の入库は自由在庫（プラント + 保管場所、特在区分は空）。E は MTO、Q は ETO。確認は MMBE / MB52、表は MARD（练习③ 3-4）。
概念 戦略グループ

3. 戦略グループ 40 の標準的な説明はどれか。

最終組立ありの計画（Planning with final assembly）
組立レベルでの計画（Planning at assembly level）
総所要量計画（Gross requirements planning）
ロット生産（Production by lot size）
40 = 最終組立ありの計画。組立レベルでの計画は 70、ロット生産は 30、総所要量計画は 11。自分のシステムの OPPT の説明文で必ず確認してください（C12）。
概念 PIR の消費

4. 戦略グループ 10（見込生産）で受注を登録したとき、PIR はどうなるか。

受注が PIR を消費し、PBED の数量も減る
PIR は消費されない（受注は在庫/所要量リストに情報として表示されるだけ）
PIR が自動削除される
受注が PIR に転記され、所要量タイプが変わる
戦略 10 は受注が net requirements の計算に入らず、PIR は消費されません（古い PIR から消減）。消費するのは戦略 40 のような「最終組立ありの計画」です（概念 2）。
概念 戦略 11

5. 戦略グループ 11（総所要量計画）の特徴として正しいものはどれか。

在庫が十分にあれば計画手配を作らない
受注が PIR を消費する
PIR を使わず受注だけで計画する
在庫を考慮せず、予測どおりに生産する（MRP3 の混合MRP区分 = 2 が前提）
戦略 11 は在庫を見ずに PIR どおり生産する（連続生産向け）。MRP3 の「混合MRP区分」に 2（総所要量的計画）を設定します（C12）。
概念 消費と消減

6. 消費（consumption）と消減（reduction）の違いとして正しいものはどれか。

消費は PIR の数量そのものを減らし、消減は表示だけを変える
両方とも MD04 上の表示だけで、PIR の表は変わらない
消費は MD04 上で起きて PIR の数量（PBED）は変わらない。消減は PIR の数量そのものが減る
消費は購買発注、消減は受注で起きる
消費は受注が PIR を食べること（PBED は不変）、消減は入库・発注の完結などで数量が実際に減ること。確認は MD04 と SE16N: PBED の比較（练习④ 4-3）。
概念 版

7. MD61 で PIR を登録するときに使う標準的な「有効版」はどれか。

版 00
版 01
版 99
版は自由に決めてよく、MRP はすべての版を見る
標準では版 00 が有効版で、MRP はこれを見ます。有効版の設定は T459U（练习① 1-2）。
概念 戦略 70

8. 戦略グループ 70 の意味はどれか。

ロット生産
最終組立ありの計画
総所要量計画
組立レベルでの計画（PIR を組立レベルに置く）
70 = 組立レベルでの計画（VSFB）。74 は「組立レベルで最終組立なしの計画」。PIR を組立（アセンブリ）単位で持ちます（C12）。
概念 MTO との対比

9. 見込生産（MTS）と受注生産（MTO）を分ける最も本質的な違いはどれか。

出荷・請求の伝票タイプが違う
需要の起点（予測 か 受注 か）と、在庫の帰属（自由在庫 か 受注在庫 E か）
製造指図を使うか使わないか
出庫確認（PGI）の移動タイプが違う
操作系（VA01/MD04/VL01N/VF01/261・101・601）はほぼ同じで、違うのは需要の起点・在庫の帰属・月末の焦点。MTS の証拠は「入库先が自由在庫（特在区分 空）」です（概念 7）。
概念 標準原価

10. MTS の在庫評価が標準原価（標準価格）で行われる理由として正しいものはどれか。

税務上の義務だから
実際原価は計算できないから
先に造って後に売るため、卖出的时点では実際原価が確定しておらず、在庫は標準価格で評価し差異を月末に処理するから
受注在庫の評価ができないから
見込生産では库存が受注より先にできます。出荷時に在庫は標準価格で評価され、実際との差は差異計算（KKS1/KKS2）と決済（KO88/CO88）で処理されます（概念 6）。

二、配置（11〜19）

配置 品目マスタ

11. MTS の完成品品目で、MRP4「個別/包括所要量」はどう設定すべきか。

空（受注に紐づけない）
1（個別所要量のみ）
2（包括所要量のみ）
どちらでも同じ結果になる
空にすることで受注に紐づかず、入库が自由在庫に入ります。「個別所要量のみ」にすると受注在庫 E に変わり、形態が MTO になります（C2）。
配置 明細カテゴリの決定

12. 明細カテゴリを決定する VOV4 の 4 つのキーとはどれか。

販売組織 / 販売チャネル / 部門 / プラント
受注タイプ / 得意先 / 品目タイプ / 数量
販売伝票タイプ / 品目カテゴリグループ / 用途 / 上位明細カテゴリ
プラント / MRPタイプ / 戦略グループ / 所要量タイプ
VOV4 は 販売伝票タイプ + 品目カテゴリグループ + 用途 + 上位明細カテゴリ。空値もキーなので、不要な値を入れると決定がずれます（C7）。
配置 明細カテゴリ TAN

13. 標準明細カテゴリ TAN の「特別在庫」の設定はどうあるべきか（見込生産）。

E（受注在庫）を入れる
空のままにする
Q（プロジェクト在庫）を入れる
どの値でも MRP の挙動は同じ
特別在庫欄が空 = 自由在庫で扱う = MTS。MTO の場合に E を入れます（表 TVAP-SOBKZ）。確認は VOV7（C6）。
配置 納入日程行カテゴリの決定

14. 納入日程行カテゴリを決定する VOV5 のキーはどれか。

明細カテゴリと MRPタイプ
販売伝票タイプと得意先
戦略グループと所要量クラス
受注タイプと出荷プラント
VOV5 は 明細カテゴリ + MRPタイプ。品目に MRP ビューが無い（MRPタイプ空）と別の納入日程行カテゴリになり、所要量転送や在庫確認の挙動が変わります（C9）。
配置 納入日程行カテゴリ CP

15. 標準の納入日程行カテゴリ CP に関する記述として最も適切なものはどれか。

所要量転送も在庫確認も行わない（納入のみ）
在庫確認は行うが、所要量転送は行わない
所要量転送は行うが、在庫確認は行わない
所要量転送と在庫確認の両方を行い、出庫確認の移動タイプは 601
CP は標準の MRP 用納入日程行カテゴリで、所要量転送・在庫確認・PGI の 601 を含みます。環境で値が違う場合があるので VOV6 と VBEP で確認してください（C8）。
配置 所要量クラス

16. 所要量クラス（OVZG）について、見込生産の理解として正しいものはどれか。

見込生産で使うクラスにも「個別在庫」を設定する
所要量クラスは所要量タイプを決めるためのもので、在庫の帰属には影響しない
見込生産系のクラスには「個別在庫」がなく、個別在庫を持つクラス（例 040）は MTO 系
所要量クラスは MRP にしか影響しない
所要量クラスの「個別在庫」フラグが E 特在の源流です。見込生産系（100/030/050 など）は個別在庫なし、MTO 系（040）はあり（C10）。
配置 消費モード

17. 消費モードと逆/順消費期間は、どこで設定するか。

計画方針グループ（OPPT）に持たせる
品目マスタの MRP3 ビュー（MARC-VRMOD/VINT1/VINT2）
所要量クラス（OVZG）
納入日程行カテゴリ（VOV6）
消費モードと逆・順消費期間は品目マスタ MRP3 が持ちます（MARC-VRMOD = 1 逆のみ / 2 逆＋順 / 3 順のみ / 4 順＋逆、VINT1 逆期間 / VINT2 順期間）。確認は MM03 MRP3（C2）。
配置 標準原価

18. 標準価格（例 8,000 JPY）を品目に反映させるための手顺として正しいものはどれか。

CK11N で標準原価を計算 → CK24 でマーク・リリースする
MM02 の会計1 で価格を直接入力する
KKS1 を実行すれば標準価格ができる
MR21 で在庫評価を変更すればよい
標準原価は CK11N（単品目）/ CK40N（一括）で計算し、CK24 でマーク（Mark）とリリース（Release）を行います。リリース後に MM03 会計1 で標準価格が見えます（C4）。
配置 Public Cloud

19. Public Cloud（S/4HANA Cloud Public Edition）で見込生産を実装するとき、正しい記述はどれか。

On-Premise と同じ SPRO で明細カテゴリを自由に新規作成できる
クラウドでは見込生産のスコープアイテムが存在しない
設定はすべて SSCUI で新規オブジェクトの作成も可能
明細カテゴリや販売伝票タイプの新規作成はできず、スコープアイテム（例 BJ5）と SSCUI で提供される範囲を使う
Cloud は「What you see is what you get」。VOV7/VOV4 での新規作成は不可で、スコープアイテム（BJ5 = Make-to-Stock Production – Discrete Manufacturing）と SSCUI（例 105120「明細カテゴリ別の所要量タイプ決定」）を使います。ID は版本で変わるため要確認（C16）。

三、流程（20〜25）

流程 MRP Live

20. MD01N（MRP Live）について正しい記述はどれか。

実行後に MD05/MD06 で MRP リストを確認するのが標準である
単品目の MRP は実行できず、必ずプラント全体で実行する
MRP リストを作成しないため、結果の確認は MD04 などで行う
購買依頼を作成できない
MRP Live は MRP リストを作りません（古典 MRP の MD01/MD02/MD03 との差異）。結果は MD04 で確認します。SAP KBA 2640393（练习② 2-1）。
流程 純所要量

21. 純所要量（正味所要量）の算式として正しいものはどれか。

総所要量 + 入庫予定 + 安全在庫
総所要量 − 入庫予定 + 安全在庫
総所要量 − 安全在庫 − ロットサイズ
受注数量 − 在庫数量
純所要量 = 総所要量（PIR + 受注 + 従属所要量） − 入庫予定（在庫 + 入庫予定） + 安全在庫。MD04 の各行から検算できます（练习② 2-2）。
流程 指図変換

22. 計画手配を製造指図に変換する標準的な手顺はどれか。

MD04 の計画手配行、または CO40（単品目）/ CO41（一括）で変換する
MD01N を再実行すると自動で指図になる
VA01 で受注を再登録すると指図ができる
CK24 でリリースすれば指図ができる
計画手配 → 指図は CO40/CO41（或は MD04 から）。指図タイプは品目 MRP2 の伝票タイプ（例 PP01）。MTO では CO08（受注明細に直結）を使うのが違いです（练习② 2-4）。
流程 261 / 101

23. 移動タイプ 261 と 101 の説明として正しいものはどれか。

261 は完成品の入庫、101 は部品の出庫
261 は購買発注への入庫、101 は出荷の出庫確認
261 は棚卸差異の転記、101 は在庫転送
261 は指図への部品出庫、101 は指図（または購買発注）への入庫
261 = 指図への部品出庫、101 = 指図/発注への入庫、601 = 出荷の出庫確認（PGI）。見込生産では 101 で自由在庫が増えます（练习③ 3-2）。
流程 受注と ATP

24. 受注を登録したときの在庫確認（ATP）の説明として正しいものはどれか。

ATP は在庫数量だけを見て判断する
利用可能在庫数量（在庫 + 入庫予定 − 出庫予定）に対して確認し、結果は CO09 や納入日程行で確認できる
ATP の結果は MMBE を見れば分かる
見込生産では ATP を使わない
ATP は利用可能在庫数量で判定します。CO09（単品目）/ MDVP（一括）/ V_V2（納期再設定）で確認。見込生産は「公共在庫を先着順で引当てる」のが特徴です（练习④ 4-2）。
流程 消費の確認

25. 受注が PIR を消費したことを確認する方法として最も適切なものはどれか。

PBED の数量が減っていることを確認する
MD61 を開き直して数量が変わったかを見る
MD04 で PIR 行の「消費済数量」を確認する（PBED の数量は変わらない）
MMBE の在庫が増えたことを確認する
消費は MD04 上で起き、PBED の数量は変わりません。消費済数量は MD04 の PIR 明細で確認します（练习④ 4-3）。

四、故障（26〜28）

故障 受注が MRP に出ない

26. 受注を登録したのに MD04 に得意先所要量が出ない。最初に疑うべきはどれか。

MRP タイプが PD になっていること
納入日程行カテゴリの「所要量転送」が OFF（VBEP-BEDSD が空）であること
標準価格がリリースされていないこと
出荷伝票がまだ作られていないこと
受注が MRP に需求として渡るかは納入日程行カテゴリの所要量転送で決まります。確認は VA03 の納入日程行 → VBEP-BEDSD → VOV6 / VOV5（故障対照表 #3）。
故障 入庫が受注在庫に入る

27. 完成品の 101 入庫が、自由在庫ではなく「得意先別（受注在庫）」に入ってしまった。原因として最も可能性が高いのはどれか。

移動タイプ 101 が間違っている
保管場所の設定が間違っている
品目マスタ MRP4 の「個別/包括所要量」が「個別所要量のみ」になっている（または指図が受注に紐づいている）
在庫確認のスコープに個別所要量が入っている
入库が受注在庫（特在 E）に入るのは、需求が受注に紐づいているからです。確認は MM03 MRP4 と CO03／SE16N: AFPO-KDAUF/KDPOS、在庫は MMBE／MSKA（练习③ 3-4）。
故障 差異計算

28. KKS2 で差異計算したところ「目標原価がありません」となった。最初に確認すべきはどれか。

標準価格が計算・リリースされているか（CK11N → CK24、MM03 会計1）
受注が登録されているか
PGI が実行済みか
棚卸が実施済みか
目標原価は標準原価（標準価格）を基準に計算されます。標準価格が未リリースだと差異計算ができません。確認は MM03 会計1（MBEW-STPRS）と CK13N、レートは KP26（练习⑤ 5-1）。

実機验收清单（合格必须全勾）

システムの証拠で確認する（申告ではなく証跡）
  • PIR：版 00 に登録され、MD04 に「計画独立所要量」が受注番号なしで表示される。
  • MRP：MD01N 後に計画手配が生成され、その在庫区分が空である（MD04/PLAF）。
  • 指図：AFPO-KDAUF/KDPOS が空である（見込生産の証拠）。
  • 入庫：101 後に MMBE の自由在庫（非制限利用）が増え、特別在庫（得意先別）が空である。
  • 受注：明細カテゴリ TAN / 納入日程行カテゴリ CP、VBEP-BEDSD（所要量転送）と ATPPR（在庫確認）が ON。
  • ATP：CO09 で利用可能数量と要素（入庫予定・出庫予定）が見え、受注で確認済数量が付く。
  • 消費：MD04 で PIR の消費済数量が増え、PBED の数量が変わっていない。
  • 出荷：PGI 601 で自由在庫が減り、MATDOC に 601 の伝票がある。
  • 請求：VF01 で請求が作成され、FB03 に会計伝票がある。
  • 差異：KKS2/KKS1 で差異が計算され、KO88/CO88 の決済で FB03 に転記される。
  • 伝票フロー：VA03 で 受注 → 出荷 → 請求 → 会計伝票 が一本につながっている。
