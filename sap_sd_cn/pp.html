1. 本模块导读

PP 主线是「主数据 → 计划 → 执行 → 成本」：生产计划参数文件、生产调度员、生产订单参数（排程 / 订单类型 / 确认）→ 物料清单 BOM（CS01，用处清单 CS15）→ 工作中心（负责人、控制码、能力 CR11、工时类别工作中心 CR01）→ 工艺路线（CA01）与工序拆分（CA02）→ 产成品生产计划视图 → 成本核算基础（成本构成结构、估计变式、日期控制、数量结构控制、成本核算变式 PC01）→ 产品成本估算（CK11N）→ 标记价格 / 发布价格（CK24）→ 实际成本核算估价变式与在制品结果分析版本 → 可用性检查（检查组、检查范围、检查规则 PP01/PP02）→ 计划策略组（MM02）与独立需求（MD61）→ MRP 运行（MD02）、MRP 清单 MD05、库存需求清单 MD04 → 计划订单转生产订单 → 采购申请转采购订单 → 收货与发票 → 生产订单下达（CO02）/ 发货 / 工单确认（CO11N）/ 收货（MIGO）→ 成本显示（CO03）/ 技术性完成 / 差异结算（KO88）/ 成本报表 → 库存清单与移库。

教材场景是一台「铸钢泵 170-230」从 BOM、工艺路线、标准成本估算，一路做到生产订单完工、结算和成本分析。

本模块重点
  • 三大主数据：BOM（CS01）、工作中心（CR01/CR11）、工艺路线（CA01）
  • 标准成本估算与价格更新：CK11N 估算 → CK24 标记 → 发布
  • 计划策略组与独立需求（MD61）→ MRP（MD02）→ 计划订单转生产订单
  • 生产订单执行链：下达 CO02 → 发货 → 确认 CO11N → 收货 MIGO → 结算 KO88

文档中出现的 T-code：CS01 CS15 CR11 CR01 KP26 CA01 CA02 PC01 CK11N CK24 MM03 PP01 PP02 MM02 MD61 MD05 MD04 MD02 COOIS MIGO MIRO MRBR CO02 CO11N CO03 KO88（完整说明见 T-code / IMG 路径速查）
