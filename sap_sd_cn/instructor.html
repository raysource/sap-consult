讲师版 — 授课设计、演示脚本与评分建议

面向用这套材料带班的讲师。本站素材来自教材文档 S4.docx： 222 个任务 / 1369 张实机画面，全部画面都是原作者在真实系统里截的中文界面。

本站的口径（讲课时请同步声明） ① 画面是原文档的实机截图，不是示意图；② 文档里的组织结构与主数据编号（C999 / F999 / R999-100 / K001 …）属于原作者的教材环境，操作顺序照做、取值换成学员系统的； ③ 本站不补充原文档没有的标准值、字段清单与 SAP Note。

1. 课时安排建议（按 5 天 / 30 小时）

任务数与画面数都很实在，讲不完是正常的 —— 建议「配置讲主线、业务全演示」： 每个模块的后台配置挑关键任务演示 1〜2 个，前台业务任务（创建订单、收货、开票）全部走一遍。

3. 必出问答（12 问，含标准答法）

#学员一定会问建议这样回答
1这套教材的配置从哪开始做？从「准备工作」的 SPRO 进后台，然后按 FI → CO → MM → PP → SD 的顺序。FI 的任务 01〜05（公司代码 / 会计科目表 / 会计年度变式 / 信贷控制范围 / 全局参数）是全部模块的公共前提，必须先做。
2为什么 FI 的第一个任务是「创建公司代码」而不是建科目？公司代码是「一个完整的会计实体」（原文档原话），后面所有科目、凭证、期间、报表都挂在这个公司代码上；教材建的是 C999「颐宁机械有限公司」。
3科目建好后，凭证里看不到某个字段（或字段是灰的）是怎么来的？由「科目组 + 字段状态变式」决定：任务 06 定义科目组及输入控制、任务 07 定义字段状态变式、任务 08 把变式分配给公司代码。所以讲科目之前必须先讲这两个。
4「材料采购科目」是干什么的？为什么又叫 GR/IR？原文档说明：收货时借「库存」贷「材料采购」，收发票时借「材料采购」贷「应付账款」，科目需要「逐笔逐清」，是收货与收发票之间的过渡科目（GR/IR），贷方余额挂在 WRX 事务码上。
5MM 里最容易出错的接缝在哪？物料主数据的「评估类」与自动记账 OBYC：评估类决定科目确定，评估类填错就会报「不可能为条目 A999 BSX CN01 确立帐户」。原文档的处理是删掉已建采购订单、改物料会计视图 1 的评估类（本期/上期/上一年度都要改），并建议在创建物料时就做对。
6税码报错 FS217 怎么处理？用 FS00 打开该总账科目，在「控制数据」里把税务类型放开：- 只允许进项税、+ 只允许销项税、* 全部允许；改完退出 MIRO 重新进入。
7PP 里标准成本估算是哪几个 T-code、什么顺序？CK11N 估算 → CK24 标记 → CK24 发布。作业价格缺失（如「没有内部作业 LAB 1001 的价格可被确定」）时，先用 KP26 维护作业输出价格，再回 CK11N——原文档特别提示：维护完要退出 CK11N 再重新执行 CK24。
8生产订单从下达到结算，现场演示的顺序是什么？下达 CO02 → 发货（对生产订单发货）→ 确认 CO11N → 收货 MIGO → 成本显示 CO03 → 技术性完成 CO02 → 差异结算 KO88 → 成本报表。（对应 PP 任务 42〜49）
9SD 里「销售范围」是什么？为什么订单一开始就要填？销售范围 = 销售组织 + 分销渠道 + 产品组，是 SD 的业务分区（任务 01〜07）。订单里的定价过程、交货、税确定、可供量都要靠它定位，所以不填销售范围什么都做不了。
10客户主数据里的合作伙伴为什么有 4 个？原文档给出的是：SP 售达方、BP 收票方、PY 付款方、SH 送达方。一个客户可以在不同角色上换别人（例如收货方 K002 作为送达方），订单里自动带出这些角色。
11一笔业务从报价走到会计凭证，演示哪几个 T-code？报价 VA21 → 销售订单（参照报价创建）→ 交货 VL01N → 发票 VF01 → 过账 VF02 → 会计凭证（点击原始凭证）→ 订单清单 VA05 / 销售分析 MCTA。
12学员系统里的报错和教材不一样怎么办？先做「排错与踩坑」页的 6 项前提检查（期间开关、组织结构分配、评估类与 OBYC、价格标记发布、库存、主数据），教材里的报错大多落在这 6 类里；再不行就用 F1/F4 与 SPRO 的文档按钮确认字段 —— 不要照抄别人的标准值。
