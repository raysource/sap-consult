学员版（记入表）

可打印：把组织值、主数据、单据号、凭证号与订单成本记下来

把课上看到的东西记成「可复述的号码与数值」：组织与主数据值 → 独立需求 → 计划订单/生产订单 → 物料凭证与会计凭证 → 成本估算与订单差异。可直接打印（浏览器打印时导航与按钮会自动隐藏）。

6. 自评（做完打勾）

能力项自评（○ / △ / ×）打 △ 或 × 时，问题在哪
能画出组织与资源关系，并说出每个对象决定什么
能说出 BOM 与工艺路线各自给 MRP / 成本提供什么
能解释「MRP 不产生正式订单」这句话
能完成 独立需求 → MRP → 计划订单 → 生产订单 的全过程
能完成 下达 → 发料 261 → 报工 → 收货 101 的全过程
能说出每一步动没动库存、有没有会计凭证
能解释标准价格、订单产出与订单差异的关系
能说出 CK11N / CK24 标记 / CK24 发布 的区别
交作业第 3–5 节的号码与数值是实操成绩依据；自评里打 △/× 的条目，回到对应页面复习（评分标准）。
