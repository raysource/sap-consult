流程① 计划

MD61 独立需求 → MD02 MRP 展开 → MD04 → 计划订单转生产订单 / 采购申请转采购订单

独立需求（PIR）与「计划订单」「采购申请」的本质区别

独立需求是计划的起点：它只是一个数字（物料 + 工厂 + 日期 + 数量），不代表任何承诺，也不占库存。教材任务 33 的做法是：从今天排到下月末，按周（周期 W）创建。

MRP 的输出分两种：自制件出计划订单（还可以被系统自动改日期），外购件出采购申请（交给采购）。两者都不是正式凭证，所以教材任务 37/39 还要人手工转换一次。

手顺④ 将计划订单转换为生产订单（MD04）

任务 37

MD04
教学要点教材现场：MRP 的两个主要结果之一（产成品的计划订单）在这里转成正式的生产订单：在 MD04 里双击计划订单行 → 看计划订单信息 → 点「生产订单」按钮完成转换，同样的方法把其他计划订单也转掉。
IMG 路径（教材后台菜单）后勤 → 生产 → 物料需求计划 → 评估 → MD04-库存/需求清单

  2. 解释：MRP 运行有两个主要结果：一个是对产成品生成计划订单，另外一个是对原材料产生采购申请。本步骤中我们将产成品的计划订单转换成正式的生产订单。
    我们可以在此清单中直接完成转换的操作

  3. 解释：屏幕中显示的是该计划订单的主要信息，在下方的一排按钮可以执行各种转换操作，我们将该计划订单转换成生产订单，点击生产订单键，点后退

  4. 原书提示点击保存
    原书提示同样的方法把其他计划订单也转化为生产订单
计划订单上的关键信息含义转换后的影响
计划订单号系统编号（MD04 行上的 PlOrd）转换成生产订单后换成生产订单号（教材得到 1000013）
开始/完成日期由提前期回排得到生产订单继承并可再排程

订单类型（转换目标）计划订单里的生产订单类型（教材用 PP01）决定可用性检查、状态管理、结算规则
状态计划订单可以随时被 MRP 改写转成生产订单后不再被 MRP 自动改写
