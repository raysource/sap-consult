概念

1. CO（管理会计）与 FI（财务会计）的分工，下列说法正确的是？

CO 是 FI 的子账，只记录工资
CO 与 FI 的数据完全独立，互不相关
CO 负责出具资产负债表与利润表
CO 面向内部管理，负责成本对象与成本流动；FI 面向对外报表
答案 D。两者共用数据（初级成本要素就是 FI 的损益类科目），但目的不同：FI 记对外账，CO 记「成本算在哪个部门/项目/产品上」。
概念

2. 分配（KSV5）与分摊（KSU5）最主要的区别是什么？

两者完全一样，只是执行顺序不同
分配会生成 FI 凭证，分摊不会
分配用次级成本要素，分摊用初级成本要素
分配搬初级成本要素、成本形态不变；分摊用次级成本要素、形态改变
答案 D。教材任务 23 的原话：分配前后成本流形态没变；分摊后接收方看到的是「电费分摊 802010」这类次级成本要素。
概念

3. 费用被记到了错误的成本中心，标准处理方式是什么？

用 KB61 重过账到正确的成本中心
直接在数据库里改行项目
只能等下个月再调整
冲销 FI 会计凭证再重新录入
答案 A。教材任务 17：CO 里用重过账改成本对象，FI 凭证完全不动 —— 不必要也不应该冲销财务凭证。
概念

4. 关于成本控制范围（Controlling Area），下列说法正确的是？

它用于定义工厂
它只在 FI 里使用，CO 不用
它就是公司代码，两者永远一一对应
它是 CO 的组织边界，一个成本控制范围可以包含多个公司代码
答案 D。教材里两者是一对一（都用 C999），所以看起来一样；概念上控制范围是 CO 的边界，可以跨公司代码。
概念

5. 下列哪一项操作不会产生 FI 会计凭证？

FB60 输入供应商发票
FB50 输入总账凭证
KSV5 执行分配（结算到成本中心）
MIGO 采购收货
答案 C。分配（以及分摊、结算到成本中心）只在 CO 内产生 CO 凭证；只有结算到固定总账科目时才会生成 FI 凭证。

2001

8. 教材的标准层次里，属于 MFG 制造部的成本中心是？

2003 销售部与 2004 市场部
2005 采购部与 2002 人力资源
2001 财务部与 2006 行政部
1001 Workshops 与 1002 Warehouse
答案 D。HQ 总部下是 2001–2006 六个管理/职能成本中心；MFG 制造部下是 1001 Workshops 与 1002 Warehouse。
组织

9. 关于成本中心标准层次，下列说法正确的是？

标准层次就是成本要素组
成本中心可以不属于任何标准层次
所有成本中心都必须挂在标准层次上，用 OKEON 维护
标准层次只能有一个层级
答案 C。标准层次是成本控制范围内的成本中心树（教材任务 04），报表按它上卷，分配/分摊循环的接收方也常选它。

2001 财务部
2006 行政部
1001 Workshops
1002 Warehouse
答案 C。任务 12：版本 0、期间 1–12、财年 2021、成本中心 1001，维护 MAC 与 SET 两个作业类型的价格。
主数据

11. 创建初级成本要素的事务码是？

KA01
KA06
KAH1
KL01
答案 A。KA01 建初级（对应 FI 损益类科目）；KA06 建次级；KAH1 建成本要素组；KL01 建作业类型。
主数据

12. 次级成本要素的典型用途不包括下列哪一项？

内部作业分配（43 类）
分摊（42 类）
结算（21/22 类）
记录供应商发票金额
答案 D。次级成本要素只在 CO 内流动，FI 里没有对应科目；供应商发票金额记在总账科目与初级成本要素上。
主数据

13. 教材里成本要素 41010901 生产成本－生产订单差异的成本要素类别是？

1 初级成本/成本降低产生的利润
43 内部作业
22 外部结算
42 分摊
答案 C。教材任务 05 的原话：除它之外，其他初级成本要素的类别都是 1；22 类专门用于生产订单差异这类结算结果。
主数据

14. 统计指标 RENT 在分配里起什么作用？

提供各成本中心的面积（M2）作为分配的比例基数
定义作业价格
它是 FI 的一个科目
记录房租金额
答案 A。统计指标只记数量；它作为分配循环的「接收方追踪因素」，决定各接收方拿多少（教材任务 18/19/20）。
主数据

M2（平方米）
KG（千克）
CNY（金额）
H（小时）
答案 D。教材画面里作业单位是 H，计划作业量各 19,200 H；价格按「每 1 小时」维护。

1001 占 75%、1002 占 25%

控制 → 内部订单 → 订单主数据 → 定义订单类型
控制 → 成本中心会计 → 主数据 → 统计指标
控制 → 内部订单 → 实际过账 → 结算 → 维护分配结构

控制 → 内部订单 → 主数据
控制 → 成本中心会计 → 期末结账

27. 「定义分配循环」的路径是？

成本中心会计 → 计划 → 作业输出/价格
成本中心会计 → 期末结账 → 当前设置 → 定义分配
成本中心会计 → 实际记账 → 重过账行项目
成本中心会计 → 信息系统 → 报表
答案 B。教材任务 20；分摊循环则在同一个菜单的「定义评估」（任务 23），执行时分别是 KSV5 与 KSU5。

28. 费用凭证要能被 CO 看到，行项目上必须填写什么？

成本对象（成本中心 / 内部订单等账户分配）
供应商编号
付款条件
物料号
答案 A。费用进了总账不等于进了成本中心；账户分配（成本中心/订单）才是 CO 的入口（教材任务 14/15/32 的现场）。

29. 产品成本里「工」这一块的金额，是按什么进到订单上的？

按人工工时手工输入金额
按物料清单自动计算
按「作业类型 × 作业价格（KP26）」计算
按采购订单价格
答案 C。报工数量乘上作业价格（教材 MAC 460/170、SET 300），作业分配用 43 类次级成本要素。

30. 关于结算的接收方，下列说法正确的是？

只能结算到成本中心
可以结算到成本中心、总账科目、资产、其他订单等；结算到固定总账科目时会生成 FI 凭证
结算不会产生任何凭证
结算必须结算到利润中心
答案 B。教材演示的是结算到成本中心（接收方类别 CTR，纯 CO 过账）；接收方是固定总账科目时系统会生成 FI 凭证。
