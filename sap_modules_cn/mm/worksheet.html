学员版（记入表）

可打印：把组织值、单据号、凭证号、科目分录记下来

把课上看到的东西记成「可复述的号码」：组织值 → 主数据 → 单据号 → 凭证号 → 科目分录。可直接打印（浏览器打印时导航与按钮会自动隐藏）。

对象教材值你的系统

2. 主数据

项你建的关键字段核对
物料号（ROH）物料组 / 采购类型 / MRP 类型 / 批量 / 安全库存 / 评估类 / 价格控制
物料号（FERT 或 HAWA）同上 + 成本核算批量
供应商号 + 采购组织数据采购组 / 付款条件 / INCOTERMS
采购信息记录净价 / 标准订单数量 / 交货时间 / 采购组

3. 采购单据链

请购号（ME51N） → 采购订单号（ME21N） → 订单行号：
订单的关键值（供应商 / 净价 / 价格单位 / 交货日期 / 工厂 / 库位）
用一句话说明：为什么订单里不用手输价格？

4. 收货与记账

项记录看哪里
物料凭证号（收货 101）MIGO 消息 / MB03
会计凭证号MIGO「文件信息」→ FI 凭证
借方科目（存货）BSX 对应的存货科目
贷方科目（GR/IR）WRX 对应的材料采购科目
库存地点与数量MMBE 对应行
收货前后库存数量MMBE / MB51

5. 发票校验

项记录说明
发票号（MIRO）参考字段要能对上供应商发票
余额是否归零归零 = 匹配成功
差异类型 / 容差码冻结时到 MRBR 看原因
借方科目（GR/IR）与收货时的贷方对应
贷方科目（应付账款）供应商统驭科目
税额与税码13% 增值税（教材缺省值）

6. 自评（做完打勾）

能力项自评（○ / △ / ×）打 △ 或 × 时，问题在哪
能画出 MM 组织结构并说出分配关系与基数
能解释物料主数据「视图 × 组织层」
能说出五类凭证的顺序与各自的 T-code
能解释收货为什么会产生会计凭证
能完成 请购 → 订单 → 收货 → 发票校验 全流程
能说出超容差会怎样、怎么处理
能解释 GR/IR 的作用与怎么查它是否平
能说出 BSX / WRX / GBB 各自决定什么科目
交作业第 3–5 节的号码与分录是实操成绩依据；自评里打 △/× 的条目，回到对应页面复习（评分标准）。
