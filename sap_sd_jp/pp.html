1. 本モジュールのガイド

PP のメインラインは「マスタデータ → 計画 → 実行 → 原価」です：生産計画パラメータファイル、生産スケジューラ、製造指図パラメータ（スケジューリング / 指図タイプ / 確認）→ 部品表（BOM）（CS01、使用箇所一覧 CS15）→ 作業区（責任者、制御コード、能力 CR11、作業時間タイプの作業区 CR01）→ 工順（CA01）と工程分割（CA02）→ 完成品の生産計画ビュー → 原価計算の基礎（原価構成構造、見積バリアント、日付制御、数量構造制御、原価計算バリアント PC01）→ 製品原価見積（CK11N）→ 価格のマーク / 価格のリリース（CK24）→ 実績原価計算の評価バリアントと仕掛品結果分析バージョン → 所要量チェック（チェックグループ、チェック範囲、チェックルール PP01/PP02）→ 計画戦略グループ（MM02）と独立所要量（MD61）→ MRP 実行（MD02）、MRP 一覧 MD05、在庫所要量一覧 MD04 → 計画手配から製造指図へ → 購買依頼から購買発注へ → 入庫と請求書 → 製造指図の指図発行（CO02）/ 出庫 / 指図確認（CO11N）/ 入庫（MIGO）→ 原価照会（CO03）/ 技術的完了 / 差異決済（KO88）/ 原価レポート → 在庫一覧と在庫転送。

教材のシナリオは、「鋳鋼ポンプ 170-230」1 台について、BOM、工順、標準原価見積から製造指図の完了、決済、原価分析までを一通り行うものです。

このモジュールのポイント
  • 3 大マスタデータ：BOM（CS01）、作業区（CR01/CR11）、工順（CA01）
  • 標準原価見積と価格更新：CK11N で見積 → CK24 でマーク → リリース
  • 計画戦略グループと独立所要量（MD61）→ MRP（MD02）→ 計画手配から製造指図への変換
  • 製造指図の実行チェーン：指図発行 CO02 → 出庫 → 確認 CO11N → 入庫 MIGO → 決済 KO88

ドキュメントに出てくる T-code：CS01 CS15 CR11 CR01 KP26 CA01 CA02 PC01 CK11N CK24 MM03 PP01 PP02 MM02 MD61 MD05 MD04 MD02 COOIS MIGO MIRO MRBR CO02 CO11N CO03 KO88（詳細は T-code / IMG パス早見表 を参照）

3. 手順（タスクごと）

このページの使い方各タスクは原教材ドキュメントの順序どおりに掲載しています。まず「説明」を読み、次に「IMG パス」に従って設定ポイントへ進み、その後は番号付きのステップに沿って（各ステップに原教材ドキュメントの実機画面が付いています）、画面ごとに操作していきます。画面の赤い四角や矢印は、原教材ドキュメントの著者が「入力・選択すべき箇所」として付けたものです。画面をクリックすると拡大できます（1×/2×/3×、ESC で閉じる）。
