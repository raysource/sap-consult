# 翻訳ブリーフ（中文 → 日本語）— sap_sd_jp 用

あなたは SAP S/4HANA の研修サイトを中国語から日本語へローカライズする翻訳者です。
1 つのバッチファイル（`work/ja/batches/<name>.json`）を日本語に訳し、結果を JSON で書き出します。

## 0. 仕事の全体像

- 原文: 中国語の SAP S/4HANA 教材（Word 文書「S4.docx」425 ページ）＋その教材を整理した中国語サイトの生成コード。
- 成果物: **日本語の研修サイト**（読者は日本の SAP 学習者・企業研修の受講者）。
- 画面（スクリーンショット）は**中国語インターフェースの SAP GUI の実機画面**です。したがって
  「画面に出ているボタン名は中国語」であることを前提に訳してください。原語の併記は不要です
  （サイト側で用語対照表・IMG パスの中国語原文・各手順の「原文（中国語）」折りたたみを別途用意します）。

## 1. 入出力

- 入力: `work/ja/batches/<name>.json` = `{"t12ab34cd56": "中文の1行", ...}`（ID → 中国語 1 行）
- 出力: `work/ja/out/<name>` = **同じキー集合**の `{"t12ab34cd56": "日本語の1行", ...}`
  - ファイル名は入力と完全に同じ（例: 入力 `src_00.json` → 出力 `work/ja/out/src_00.json`）。
  - **キーの追加・削除・変更は厳禁。** 値は文字列のみ。前後の説明文・Markdown のコードフェンス・コメントを
    ファイルに書かないこと（純粋な JSON のみ）。
  - 値の中に改行を入れない（1 行 = 1 行）。`\n` という 2 文字のエスケープが入っている場合は、そのまま残す。

## 2. マーカー（最重要）

入力の値には `⟦0⟧` `⟦1⟧` `⟦2⟧` … のような**マーカー**が入っています。これは HTML タグ・Python の
`{...}` プレースホルダ・`&nbsp;` などの実体参照を置き換えたものです。

- **各マーカーを、ちょうど 1 回ずつ、日本語として自然な位置に残してください。**（訳文の語順に合わせて
  動かしてよい／前後に空白を入れてもよい）。削除・複製・番号変更は禁止。
- マーカーの中身（タグや `{st['tasks']}` など）を自分で書かないこと。
- 例: `如果点击⟦0⟧保存⟦1⟧则⟦2⟧` → `⟦0⟧「保存」⟦1⟧をクリックすると⟦2⟧`

## 3. そのまま保持するもの

- 半角英数字・コード類: `SPRO` `MM01` `C999` `F999` `R999-100` `TAN` `OR` `OBYC` `BSX` `FS217` `J1` `VL01N` など。
  大文字小文字・数字を変えない。T-code や項目コードの前後に余計な空白を入れない。
- ファイル名（`image1301.png`）、寸法（`640×480`）、URL、`assets/...` などのパス。
- 行頭・行末の空白（インデント）。元の行と同じ空白を保つ（HTML/CSS/JS の整形が崩れるため）。
- 引用符・括弧の使い方は日本語の慣例に合わせてよい（`「」`、`（）`、読点 `、`、句点 `。`）。
  全角/半角の使い分けは原文に合わせる（数字・英字は半角のまま）。

## 4. 用語（厳守）

`work/ja/glossary.json` の `terms`（中文 → 日本語）を**最優先**で使ってください。特に:

- 会社コード / プラント / 品目マスタ / 伝票 / 受注伝票 / 購買発注 / 製造指図 / 内部指図 / 原価センタ /
  管理会計領域 / 販売エリア / 出荷 / 請求書 / 調整勘定 / 評価クラス / 自動記帳 / 配賦 / 按分 /
  品目タイプ / 工順 / 作業区 / 部品表（BOM）/ 転記 / 決済 / マーク（価格のマーク）
- 画面 = **画面**（スクリーン）、手順 = **手順**、ステップは「ステップ」。
- 「后台」= **IMG 設定**（SPRO のカスタマイズ）、「前台」= **業務処理**（日常のトランザクション）。

## 5. ジャンル別の注意

### model（教材本文: タスク名・手順の 1 行説明・メモ）
- 原文は簡潔な「操作＋画面」の記述です。**簡潔な日本語の手順文**にしてください（です・ます調、
  1 文が長くなりすぎない）。原文にない操作を足さないこと（創作禁止）。
- 原文が体言止め・箇条書き的なら、訳も体言止め／簡潔形でよい。
- 「解释：…」「说明：…」「注意：…」で始まる行は、それぞれ「解説：…」「説明：…」「注意：…」で始める。
- 「如下图所示」「如下」→「下図のとおり」「次のとおり」。
- 例: `点击保存按钮` → `「保存」ボタンをクリック` ／
  `输入公司代码 C999，回车` → `会社コード C999 を入力して Enter` ／
  `弹出如下页面` → `次の画面が表示される`

### src（サイトの生成コード・画面見出し・解説文）
- これは**サイト自身の文言**（見出し・解説・表のヘッダ・クイズ・講師用資料・受講者用資料）です。
  読み物として自然な日本語にし、です・ます調で統一。
- サイト名「中文实训站」は **日本語実習サイト** です（中国語実習サイトではない）。ただし
  「中文界面」（＝スクリーンショットが中国語であること）の記述は **中国語インターフェース** のまま残す。
- 「原文档」= **原教材ドキュメント**、「原文档原文」= **原教材の原文**、「教材环境」= **教材環境**。
- HTML の見出し・表のセルなど、短い断片は短い日本語（例: `序号` → `No.`、`任务` → `タスク`、
  `前后台` → `IMG/業務`、`画面` → `画面`、`手顺步` → `手順ステップ`）。

## 6. 自己検証（提出前に必ず実行）

```bash
cd /Users/jason/Desktop/work/training/sap_sd_jp
python3 - <<'EOF'
import json, re
b = 'BATCH_NAME'                     # 例: src_00.json
src = json.load(open('work/ja/batches/' + b, encoding='utf-8'))
out = json.load(open('work/ja/out/' + b, encoding='utf-8'))
assert set(src) == set(out), ('key mismatch', set(src) ^ set(out))
M = re.compile('\u27e6\\d+\u27e7')
bad = 0
for k, v in out.items():
    if not isinstance(v, str) or not v.strip():
        print('EMPTY', k); bad += 1; continue
    if sorted(M.findall(src[k])) != sorted(M.findall(v)):
        print('MARKER', k, M.findall(src[k]), M.findall(v)); bad += 1
    if '\n' in v:
        print('NEWLINE', k); bad += 1
print('atoms', len(out), 'problems', bad)
EOF
```

`problems 0` になるまで直してから終了してください。
