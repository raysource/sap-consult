SD 受注生産（MTO）实战训练站

一条完整可跑的 受注生産（Make-to-Order / MTO） 场景：受注 → 得意先個別在庫（特在 E）→ MRP → 製造指図 → 完成品入庫 → 出荷・出庫確認 → 請求。 本站分两层：练习配置（VOV4 / VOV7 / VOV5 / VOV6 / OVZG / OVZI / OPPS 的 SPRO 手顺，逐步给到输入值与确认方法）与 练习流程（VA01 起的 5 个实操练习，每个练习都有输入值表、操作手顺、期待结果、故障对策、验收清单）。 主口径为 S/4HANA On-Premise，同步给出 Public Cloud（SSCUI / スコープアイテム） 的差异对照。

1. 这个场景教什么

SAP 的「受注生産（MTO）」不是单一模块的功能，而是 SD（受注・出荷・請求）× PP（所要量・指図）× MM（在庫・入出庫）× CO/FI（評価・差異）四块拼起来的机制。 它的关键点只有一个：需求与库存都要「按受注明细」区分开——这就是「得意先個別在庫（特別在庫区分 E）」。一旦这一点没配好， 后面所有症状都会出现：MD04 看不到需求、计划订单不生成、生产订单吃不到销售订单库存、交货时无法引当、销售订单库存不被评估。

① 练习配置手顺（详细 SPRO）

C0〜C16 共 17 个 STEP：从品目主数据（销售组织2 / MRP1〜4 / 会计）到 明細カテゴリグループ・明細カテゴリ・納入日程行カテゴリ・所要量タイプ／クラス・計画方針グループ 的逐项配置，每步给出 IMG 路径、事务码、输入值、在自系统中的确认方法。

配置约 150 分

② 练习流程（5 个实操）

练习① 受注与所要量转送 → 练习② MRP 与製造指図 → 练习③ 部品出庫・実績・完成入庫 → 练习④ 出荷・出庫確認・請求 → 练习⑤ 组立处理（自働指図）与差异结算。每个练习都是「照做即可」的详细手顺 + 期待结果 + 验收清单。

实操约 240 分

③ 术语与设计（为什么会这样）

MTS / MTO / 组立处理的差异、明細カテゴリ 4 键决定逻辑、所要量タイプ → 所要量クラス → 個別在庫 E 的传递链、相关表（VBAK/VBAP/VBEP/VBBS/MSKA/AUFK…）与 S/4HANA 变更点（MRP Live、受注在庫の評価）。

概念约 60 分

④ 能力测试 + 验收清单

27 题（概念 / 配置 / 流程 / 故障）× 点击判分 + 解说，外加一份实机验收清单：按清单把系统里的证据（受注明細、MD04、MMBE 特在 E、伝票フロー）逐条核对，才能算「这个场景跑通了」。

测试约 30 分

7. 关于标准值的立场（请务必读）

本教程的做法 SAP 的标准设定会随版本、行业解决方案、激活的业务功能、以及既有项目改造而不同（例如：受注生産用の所要量クラスは 040 系か評価付の 046 系か、 明細カテゴリ TAK 是否存在于标准（SAP Note 2708455 明确说明 TAK 并非 Sapp 标准定义，很多项目是自己建的）， 受注在庫の評価の扱い（S/4HANA Cloud 的 MTO 场景以 評価付の販売伝票在庫（評価区分 M） 为前提）等）。
因此本站的原则是：把「标准值的通常情况」写清楚，但每一个值都配一条「在你自己的系统里怎么确认」的手顺， 并给出配置练习（自己建 Z001 / ZTAK / ZCP / Z040）确保即使标准值与本站不同，练习依然成立。教学以「机制正确」为优先，不以背标准值为目标。
