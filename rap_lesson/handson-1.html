手顺① 数据模型准备（建表 + 造数）

本页对应 WBS PH0.2（包/TR）+ PH3 3.1 的前置 + 统合项目 STEP1。完成基准：SE11 中三张 Z 表可用，SE16N 可见 ≥5 条测试数据。

STEP 1-1 创建包与 Transport（WBS PH0.2）

  1. ADT（Eclipse）连接 S/4：Project Explorer → 右键 → New → ABAP Project（输入系统、客户端、账号）。确认可浏览包与表。
  2. 建包：右键项目 → New → ABAP Package → 名称 Z_WBS_DEV，说明「RAP 学习用（WBS 实训）」；Software Component 选 HOME，Transport Layer 用默认（SAP）。创建时选择 创建 Transport Request。
  3. 确认 TR：若弹出 Transport Request 对话框，新建 Workbench TR（类型：开发/更正）。后期所有激活对象应归属该 TR（或系统自动分配）。
  4. 备用：也可以在 SE03 / STMS 中查看 TR。若环境已有项目包（如 ZPURORDER_APP），可跳过新建，直接使用。
注意事项（WBS 备注引用） ① 本地产包 $TMP 不能上传输请求，实训中请务必用正式包。② 自定义对象一律 Z/ZZ 开头，禁止直接改 SAP 标准对象。

STEP 1-2 创建三张表（SE11 / ADT）

按统合项目 Sheet③「【数据模型】作成するZテーブル」定义。三张表结构如下（建议 ADT：右键包 → New → Other ABAP Repository Object → Dictionary → Database Table）：

表 1：z_po_hdr（采购订单头，RAP Root 的数据源）

字段Key数据类型说明
mandt✓（自动）CLNT 3客户端（SE11 自动加）
po_num✓CHAR 11采购订单号（Z+10位，本教程由番号范围 ZNPO 分配）
po_dateDATS 8采购日期（Determination 自动补默认）
vendor_codeCHAR 10供应商代码（关联 z_vendor_txt）
statusCHAR 10状态：NEW / CONFIRMED / CANCELLED
created_byCHAR 12创建人（Determination 自动填入当前用户）
zz_memoCHAR 100备注（对应 WBS 统合项目里的追加字段落点）

表 2：z_po_itm（采购订单明细，RAP Child）

字段Key数据类型说明
mandt✓（自动）CLNT 3客户端
po_num✓CHAR 10订单号（父键）
item_num✓NUMC 4行项目号（如 0010/0020）
matnrCHAR 40物料/商品代码（简单字符即可）
qtyQUAN 15,3数量（维护单位）
unitUNIT 3单位（EA/PC 等，可带检查表）
net_priceCURR 15,2单价
currencyCUKY 5币种（JPY/USD 等）

表 3：z_vendor_txt（供应商主数据简单表）

字段Key数据类型说明
mandt✓（自动）CLNT 3客户端
vendor_code✓CHAR 10供应商代码
vendor_nameCHAR 80供应商名称（列表显示用）
countryCHAR 3国家
数据元素建议 字段建议用统一前缀数据元素（如 ZPO_NUM、ZVENDOR_CODE 等），也可在 ADT 建表向导里直接选择“内置类型 + 预定义”。Quantity/Currency 字段（QUAN/CURR）在 SE11 需要“参考表/参考字段”维护（如 qty 参考 ekpo-menge 或自建参考），若嫌麻烦可先全部用 CHAR/DEC 简化，教程代码不受影响。

STEP 1-3 激活并检查

  1. 每张表保存后 激活（Ctrl+F3），激活日志无错误。
  2. Project Explorer → 双击表 → 上方「内容 / Contents」页签可看到空表；或用 SE16N 输入表名回车确认可访问。
  3. （可选）在表上追加管理字段：创建人/创建时间等。本站为聚焦 RAP，用 determination 写 created_by，不额外加时间戳。

STEP 1-4 造数（≥5 条测试数据）

  1. 先给 z_vendor_txt 造 3〜5 家供应商（vendor_code 如 0000000001～0000000005，名称任写）。
  2. 再给 z_po_hdr + z_po_itm 造 2〜3 张订单、每张 2〜3 行明细（合计明细 ≥5 行）。
  3. 用 SE16N 逐张维护；或复制下方 ABAP 程序在 SE38/ADT 运行一次（会覆盖式插入示例数据，适合练习环境）。
abap · 示例造数程序（可复制，需在可写系统运行）
REPORT zrap_seed_data.

" 1) 供应商
DELETE FROM z_vendor_txt.
INSERT z_vendor_txt FROM TABLE @( VALUE #(
  ( vendor_code = '0000000001' vendor_name = 'ABC Trading'  country = 'JP' )
  ( vendor_code = '0000000002' vendor_name = 'XYZ Parts'    country = 'DE' )
  ( vendor_code = '0000000003' vendor_name = 'Global Foods' country = 'US' ) ) ).

" 2) 订单头 + 明细
DELETE FROM z_po_hdr.
DELETE FROM z_po_itm.
INSERT z_po_hdr FROM TABLE @( VALUE #(
  ( po_num = '4500000001' po_date = '20260901' vendor_code = '0000000001' status = 'NEW'       created_by = sy-uname )
  ( po_num = '4500000002' po_date = '20260902' vendor_code = '0000000002' status = 'CONFIRMED' created_by = sy-uname ) ) ).
INSERT z_po_itm FROM TABLE @( VALUE #(
  ( po_num = '4500000001' item_num = '0010' matnr = 'MAT-100' qty = 10 unit = 'EA' net_price = '1000.00' currency = 'JPY' )
  ( po_num = '4500000001' item_num = '0020' matnr = 'MAT-200' qty = 5  unit = 'EA' net_price = '2500.00' currency = 'JPY' )
  ( po_num = '4500000002' item_num = '0010' matnr = 'MAT-300' qty = 2  unit = 'PC' net_price = '80.00'   currency = 'USD' ) ) ).

IF sy-subrc = 0.
  WRITE 'OK: vendor=3, header=2, item=3'.
ENDIF.
⚠ DELETE 有风险 上面程序会 删除整表数据，只应在练习环境/空表使用。真实系统请改用 SE16N 逐条添加。

验收（完成基准）

✓ 手顺①验收清单
  1. 包 Z_WBS_DEV 存在且绑定 TR；
  2. 三张表已激活，SE16N 均可打开；
  3. 供应商 ≥3 条，订单头 ≥2 条，明细 ≥3 行（统合项目 STEP1 基准：数据 5 件以上确认 OK）；
  4. （可选）已试过 Data Preview / SE16N 查看。
