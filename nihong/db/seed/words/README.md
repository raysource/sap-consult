# 词库种子（words/*.json）

本站「词汇」模块的词库种子，与 `db/seed/legacy/data-vocab.js` 合并入库：
旧「汉字读音池」(177) + 旧「速查表」(68) 自动并入（`src='kanji'/'ref'`），本目录提供约 2300 条新增 N2 核心词（`src='core'`），分五批：

| 文件 | 词性 |
| --- | --- |
| `words-01-名词.json` | 名（1222 条） |
| `words-02-动词.json` | 動（734 条） |
| `words-03-形容词.json` | 形 / ナ形（187 条） |
| `words-04-副词接续.json` | 副 / 接続（127 条） |
| `words-05-补充.json` | 名 / 他 / 杂项（55 条） |

> 五批合计 2325 条，`w` 全库唯一（重复时旧数据优先、本词条跳过）。

## 条目格式

每个 JSON 文件是一个数组，元素：

```json
{ "w": "渋滞", "kana": "じゅうたい", "mean": "堵车", "pos": "名" }
```

| 字段 | 必填 | 说明 |
| --- | --- | --- |
| `w` | ✔ | 表记。汉字词写汉字；纯假名/外来语副词写假名。**全库唯一**（重复时旧数据优先、本词条跳过） |
| `kana` | 汉字词必填 | 读音（平假名）。**纯假名词条留空 `""`**，不会进“汉字读音抽题/闪卡”池，但会出现在词汇库/速查 |
| `mean` | ✔ | 中文释义（简洁） |
| `pos` | 建议 | 词性：`名` `動` `形` `ナ形` `副` `接続` `他` |

## 维护

- 增删改词条后执行：`node db/seed.js --force && node db/verify.js`（只重建内容表，进度不清除）。
- 校验断言：全库 ≥2000 词、含读音 ≥1800、无重复 `w`、`mean` 非空。
- 批量校对可用表格软件导出，再转成上面的 JSON。
