# N2 道場 — JLPT N2 备考学习网站

目标 **2027 年 7 月 JLPT N2 合格** 的本地学习站点。界面中日对照，内容为日语；覆盖 N2 考试的全部题型。课程数据与学习进度存于本地 SQLite，经一个零依赖的 Node 服务提供（**无需联网、无需构建**）。

**使用方式：`node server.js`（首次自动建库 + 灌入约 2000 词与全部题库）→ 打开 http://127.0.0.1:4397**。要求 Node ≥ 23.4（本项目在 Node v26 上验证，`node:sqlite` 免标志、零 npm 依赖）。

## 内容覆盖（对应 N2 出题形式）

| 模块 | 对应题型 |
| --- | --- |
| 🈳 文字·词汇 | 问题1 汉字读音 / 问题2 表记 / 问题3 语境选词 / 问题4 近义替换 / 问题5 用法判断 + 副词·接续词速查表 + 闪卡 + **📚 全词库检索（约 2000 词，可搜索 / 按词性筛选 / 标记已认）** |
| 🈴 语法 | 72 条 N2 核心句型参考（含接续·例句） / 语法形式选择 / 句子组合（★ 排序）/ 篇章语法 |
| 📖 阅读 | 短文（150~200 字）/ 中文（350 字）/ 长文 / 统合理解（多文本）/ 主张理解 / 信息检索 |
| 🎧 听力 | 课题理解 / 要点理解 / 概要理解 / 即时反应 / 统合理解 ×2 —— 用浏览器语音合成（TTS）朗读 |
| ✍️ 综合模拟考 | 从四大模块随机抽题（汉字读音抽题已覆盖全词库），交卷自动评分并按板块给出正确率 |
| 📊 学习报告 | 累计练习数、正确率、分项正答率，自动标记薄弱板块 |

另有 **首页倒计时**（距 2027-07 考试）与 **十个月学习计划**（可勾选完成、进度自动保存）。

## 使用方法

- `node server.js` → 浏览器打开 http://127.0.0.1:4397（详见下方“启动与常用命令”）。
- 左侧导航切换模块；侧栏在小屏会自动收起（左上角 ☰ 展开）。
- 听力类题目建议先「盲听 → 作答 → 显示原句 → 跟读」；可在听力首页调节语速、开启盲听模式。
- 「词表闪卡」把不认识的汉字词逐张翻面记忆，「认识」过的词会跳过并写入数据库。
- 右上角 🌙/☀️ 切换明暗主题（跟随系统为 🌓）。

## 启动与常用命令

```bash
node server.js            # 启动服务（内容表为空时自动建库 + 灌数据）→ http://127.0.0.1:4397
PORT=8080 node server.js  # 自定义端口

node db/seed.js           # 从种子源重建内容库（词库增删改后重灌；绝不触碰学习进度）
node db/verify.js         # 内容完整性断言（非零退出即失败，CI/日常自检用）
node --check js/app.js server.js db/seed.js db/verify.js lib/db.js
```

> 旧版本（双击 `index.html`、进度存 localStorage）里的已有进度会在**首次**打开时自动迁移进数据库一次，迁移幂等、不重复。

## 项目结构

```
nihong/
├─ package.json            # scripts: start/seed/verify（无 dependencies，CommonJS）
├─ server.js               # Node http：静态文件 + /api 读写；首启自动灌库
├─ lib/db.js               # 唯一 SQLite 适配点（建表 / 事务 / JSON 列）；换 better-sqlite3 只改这里
├─ db/
│  ├─ n2.sqlite            # 运行时生成（已 git 忽略）
│  ├─ seed.js              # 从 db/seed/ 重建内容表（单事务、可重复运行）
│  ├─ verify.js            # 完整性断言（条数 / 唯一 / 选项合法 / 与源逐条回读）
│  └─ seed/
│     ├─ legacy/           # 原 js/data-*.js 题库（逐字节保留，作种子源）
│     └─ words/*.json      # N2 核心词分批种子（见下方“词库维护”）
├─ index.html              # 入口（数据经 /api 注入）
├─ css/style.css           # 设计令牌 + 组件样式（朱红×墨蓝，明/暗主题）
└─ js/app.js               # 异步 boot / 路由 / 练习引擎 / 闪卡 / 模拟考 / 统计 / TTS
```

> 内容均为原创整理，非官方真题；建议搭配官方模拟题与市售教材（如「新完全マスター」系列）使用。

## 词库维护（db/seed/words/）

按批分组为 `words-01-名词.json` … 各文件是条目数组，每条约：

```json
{ "w": "渋滞", "kana": "じゅうたい", "mean": "堵车", "pos": "名" }
```

| 字段 | 说明 |
| --- | --- |
| `w` | 表记（含读音的汉字词；纯假名词也可，只是不进读音抽题池） |
| `kana` | 读音（可空） |
| `mean` | 中文释义 |
| `pos` | 词性：名 / 動 / 形 / ナ形 / 副 / 接続 / 他（“词汇库”页筛选用） |

改完运行 `node db/seed.js` 重建；`w` 与旧题库重复时旧题库优先、新增条目跳过（seed 会打印跳过条数）。

## 数据与隐私

- 课程数据 + 学习进度（做题记录 / 计划勾选 / 已认词 / 主题·目标·语速设置）都存于本地 `db/n2.sqlite`（WAL 模式）。
- 进度仅经本机 HTTP API 读写，**不上传任何外部服务器**；服务只监听 127.0.0.1。
- 听力朗读使用浏览器自带的日语语音（`speechSynthesis`），音色因系统而异。
- 重置进度：学习报告页「清除练习记录」/ 学习计划页「重置全部进度」；也可停服后删掉 `db/n2.sqlite`（下次启动重建内容、进度归零）。

## API 一览（同源 JSON，无鉴权）

- `GET  /api/catalog` —— 全量课程数据（重组为与原题库同构的结构，直接喂练习引擎）
- `GET  /api/state`   —— `{ settings, done, known, log(近 3000) }`
- `POST /api/attempts|done|known|settings`；`POST /api/migrate`（旧 localStorage 一次性迁移，幂等）
- `DELETE /api/reset/{attempts,done,known}`
